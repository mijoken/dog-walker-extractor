# v0.2 Experiment A

## Status

PROMISING EXPERIMENT - REQUIRES NEW OUT-OF-SAMPLE VALIDATION

## Hypothesis

Reduce only the duration-factor saturation constant used by the
person-dog association score:

- frozen v0.1: sqrt(common_span_sec / 3.0)
- experiment A: sqrt(common_span_sec / 2.5)

All event acceptance thresholds remain unchanged:

- minimum pair score: 0.55
- minimum pair span: 1.0 s
- minimum dog frames: 5
- event merge gap: 1.5 s

The frozen v0.1 implementation remains unchanged.

## Motivation

Previous out-of-sample validation repeatedly showed that a real dog
walker can be missed when the dog is visible for only a short period,
even when the dog/person relationship evidence is otherwise strong.

Experiment A tests whether the duration penalty is slightly too severe
for approximately 1-2 second high-quality associations.

## Key recovered case

Blind Validation 002, Candidate 006:

- Person track: 85
- Dog track: 123
- Dog frames: 41
- Pair span: 1.33 s
- Dog coverage: 1.000
- Base score: 0.763

Frozen v0.1:

- final pair score: approximately 0.509

Experiment A:

- final pair score: 0.557
- result: accepted
- source-video event: 15:57.10 - 15:58.43

## Validation 001

Both previously confirmed dog-walking events remain detected.

## Validation 003

The previously detected dog-walking passages remain detected.

The existing over-segmentation behavior in Candidate 007 is unchanged.

Known negative candidate windows involving skirt, handbag, runner,
wheeled case, and stroller remain free of final dog-walker events.

## Interpretation

Experiment A improves the current regression set without introducing a
final-event false positive in the reviewed negative windows.

This is evidence that the 3.0-second duration saturation may be slightly
too conservative.

However, the 2.5-second value was selected after inspecting previous
validation failures. Therefore Validations 001-003 must no longer be
treated as independent evidence for choosing this parameter.

Experiment A must not be promoted to the production/frozen algorithm
until it succeeds on a new unseen video.

## Next step

Run a completely new Blind Validation 004.

The video must not be manually annotated or used to tune parameters
before the frozen experimental pipeline makes its predictions.

Only after predictions are frozen should human review establish the
ground truth.

The primary question is whether the short-duration improvement
generalizes without increasing false positives.
